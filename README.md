# Amber City / 琥珀城

2D top-down pixel crime-life prototype made with Tuanjie/Unity 2022.3.

## Included

- Brick Row city prototype (D6–H8)
- Gold Arch police-station placeholder block
- Oren River and bridge
- Convenience store, restaurant, bar, auto repair, nightclub, warehouse, port office interiors
- Bus driving and fixed route
- Convenience store, restaurant, transport, auto repair, warehouse jobs
- Lockpicking, burglary noise, neighbour reporting, police and gang responses
- Skill XP and levels
- Basic save/load at the safehouse bed

## Requirements

- Tuanjie 2022.3.62t16 or compatible Unity 2022.3
- Input System
- Built-in render pipeline

## Open

Open the `crime` folder as a Unity/Tuanjie project.

## Controls

- `WASD`: move / drive
- `Shift`: sprint
- `F`: interact / enter / exit / drive
- `C`: hold to search containers
- `E`: inventory
- `Space`: cooking/repair timing, bus brake
- `Esc`: close dialogue/panels

## Notes

- Runtime prototype content is built from `MovementTestBootstrap`.
- No design documents are included in this repository.
- The public copy has the local editor MCP dependency removed from `Packages/manifest.json`.
